# Puck for Windows — 수동 검증

자동화하기 어렵거나 비싼 것들. 릴리스 전에 한 번씩 손으로 확인한다.

`[x]`는 2026-08-24에 스크립트로 실제 앱을 띄워 확인한 것이고, 어떻게 확인했는지는
아래 "확인 방법"에 적었다. `[ ]`는 이 장비에서 재현할 수 없어 사람이 봐야 한다.

## Phase 1 — 펫

- [x] 트레이 아이콘이 뜨고, 메뉴 네 항목이 전부 동작한다.
- [x] 오버레이 배경이 투명하다 (사각형 상자가 보이지 않는다).
- [x] 펫이 스스로 걷고, 진행 방향에 맞게 좌우로 뒤집힌다.
- [x] 그림이 화면 가장자리에서 잘리지 않고 멈춘다.
- [x] 그림 위 클릭은 펫이 받고, 주위 여백 클릭은 아래 창으로 통과한다.
- [x] 드래그로 들어 올렸다 놓으면 떨어지고 바닥에서 튕긴다.
- [x] 세게 던지면 옆벽에서 튕기고, 화면 밖으로 나가지 않는다.
- [x] 테두리 없는 전체화면 topmost 창 위에서도 펫이 보인다.
- [ ] **배타적 전체화면**(DirectX 독점 모드) 게임 위에서의 동작. 위와 다른 경로다.
- [ ] 배율이 다른 두 모니터를 오갈 때 펫 크기가 각 모니터에서 맞다.
      (개발 장비는 두 모니터 다 100%라 재현하지 못했다.)
- [x] 모니터를 뽑았다 꽂아도 펫이 화면 밖에 남지 않는다. — 코드 경로만
      단위 테스트로 확인했다(`FallBringsThePetBackWhenItsDisplayIsUnplugged`).
      실제 착탈은 한 번 해 보는 편이 좋다.
- [x] 절전에서 복귀했을 때 펫이 한 프레임에 순간이동하지 않는다.
- [ ] 화면 잠금 후 복귀했을 때 오버레이가 여전히 최상단이다.
- [x] 작업표시줄 자동 숨김을 켜고 껐을 때 착지 높이가 따라온다.
- [x] `%LOCALAPPDATA%\Puck\Avatars\`에 mac에서 만든 아바타 폴더를 넣고
      "아바타 다시 불러오기"를 누르면 앱을 끄지 않고 바뀐다.
- [x] 매니페스트가 깨진 아바타가 섞여 있어도 나머지가 보이고, 이유가
      `logs\*.jsonl`에 남는다.
- [x] 트레이 → 종료 후 작업 관리자에 `Puck.exe`가 남지 않는다.

## 확인 방법

손으로 다시 볼 때 같은 방식으로 재현할 수 있게 적어 둔다.

- **투명·최상단·클릭스루** — `GetWindowLong(GWL_EXSTYLE)`가
  `LAYERED|TOPMOST|TOOLWINDOW`를 갖고, 커서를 그림 위에 두면 `WS_EX_TRANSPARENT`가
  꺼지고 여백에 두면 켜진다.
- **화면 캡처** — 레이어드 창은 `Graphics.CopyFromScreen`에 안 잡힌다.
  `BitBlt`에 `CAPTUREBLT`(0x40000000)를 줘야 보인다.
- **클립 전환** — 클릭 전후로 펫 영역을 캡처해 픽셀을 비교하면
  `react_click`(mac dummy에서는 `startled`) 그림으로 바뀐 것이 보인다.
- **던지기** — `mouse_event`로 누르고 700px를 ~150ms에 끌고 놓으면
  왼쪽 벽까지 날아가 튕겨 나온다. 그림 왼쪽 한계(폭의 절반)를 넘지 않는다.
- **전체화면** — 펫이 있는 모니터를 덮는 테두리 없는 topmost 폼을 띄우고
  펫 영역을 캡처한다. 여백은 폼 색으로, 펫은 그림으로 나와야 한다.
- **작업표시줄 자동 숨김** — `SHAppBarMessage(ABM_SETSTATE, ABS_AUTOHIDE)`로
  켜고 끈다. 켜면 발 y가 작업 영역 바닥에서 화면 바닥으로 내려가고,
  끄면 돌아온다. (`Screen.WorkingArea`는 프로세스마다 캐시되므로 확인하는
  쪽에서도 다시 열거해야 한다.)
- **절전 복귀** — 컴퓨터를 재우는 대신 `NtSuspendProcess`로 Puck을 5초
  정지시켰다 `NtResumeProcess`로 깨운다. 프레임 루프가 보는 dt는 절전과
  같은 모양이 된다. 첫 프레임 이동이 `CompositionFrameClock.MaximumDelta`
  (0.1초)치를 넘지 않아야 한다 — 상한이 없으면 5초치인 약 450px을 뛴다.
